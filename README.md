# Beyond the Brief

The creative portfolio of Muzammil Siraj.

This repository contains a self-contained, responsive portfolio in `index.html`. Project imagery is embedded in the page, so no separate asset setup or build step is required.

## View locally

Open `index.html` in a browser.

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select the default branch and the `/ (root)` folder, then save.
